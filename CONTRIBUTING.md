# Contributing

Claudette is open source, not open contribution in the usual sense. This is a personal
project, maintained in my spare time and shared as-is: there is no guarantee of support, of a
response, or that a suggestion will be implemented.

- **Bugs and ideas**: open an issue. Say what you did, what happened and what you expected.
- **Larger changes**: please open an issue to discuss it before writing code. A pull request
  that arrives without that conversation may be closed unread.
- **Pull requests** are never merged on GitHub. This repository is the published part of a
  larger private development repository, which holds the full design history and the
  reasoning behind every feature. Any pull request is likely to be completely rewritten
  before any publication.
